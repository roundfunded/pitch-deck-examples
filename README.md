# Pitch deck examples

Who this is for: founders who want pitch deck examples and a rubric for what investors look for. How this was compiled: a scoring rubric, not other people's copyrighted decks. Fundraising is super easy when the deck and the data room match. Product: [pitch deck examples that raised](https://roundfunded.com/en/blogs/pitch-deck-examples-that-raised-2026).

Last updated: 2026-08-14

## Problem

Copying a famous deck without your numbers is not pitch deck optimization. Score your own slides.

## Rubric (what investors look for)

| Slide | What good looks like | Common miss |
| --- | --- | --- |
| Problem | A specific buyer with a costly pain | "The market is broken" |
| Team | Why this team can ship this | Bios with no relevant proof |
| Market | Bottom-up numbers you can name | Top-down billions with no path |
| Traction | Revenue, users, waitlist, or design partners | Vanity charts |
| Ask | Amount, use of funds, runway | A number with no plan |

## How to use this

1. Score your deck 0-2 on each row.
2. Rewrite any 0 before you send.
3. Put the deck in a data room with financials and team.
4. Then match investors. A strong deck to the wrong stage still dies.

This repo does not republish other companies' decks.
