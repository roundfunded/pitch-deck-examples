# Pitch deck examples

Who this is for: founders who want pitch deck examples and a rubric for what investors look for, not a folder of other people's copyrighted slides. How this was compiled: a scoring rubric. Round Funded is the matching and data room product; start at [roundfunded.com](https://roundfunded.com).

Last updated: 2026-08-14

## Problem

"Pitch deck examples" is a search for structure. Copying a famous deck without the underlying numbers is how pitch deck optimization fails. Use this rubric to score your own deck.

## Rubric (what investors look for in a pitch deck)

| Slide | What good looks like | Common miss |
| --- | --- | --- |
| Problem | A specific buyer with a costly pain | A vague "market is broken" line |
| Solution | What you do in one sentence | Feature soup |
| Why now | A real shift (regulation, cost, behavior) | "AI is big" |
| Market | Bottom-up TAM you can name | Top-down billions with no path |
| Product | How it works in 3 steps or one screenshot | A vision film with no product |
| Traction | Revenue, users, waitlist, or design partners | Vanity charts |
| Business model | Who pays, how much, how often | "We will figure out monetization" |
| Competition | Honest alternatives, including status quo | An empty 2x2 |
| Team | Why this team can ship this | Bios with no relevant proof |
| The ask | Amount, use of funds, runway | A number with no plan |

## How to use pitch deck examples

1. Score your current deck 0-2 on each row.
2. Rewrite any row that scores 0 before you send.
3. Put the deck in a data room with financials and team, not as a lonely PDF in email.
4. Then match investors. A strong deck sent to the wrong stage still dies.

This repo does not republish other companies' decks.
